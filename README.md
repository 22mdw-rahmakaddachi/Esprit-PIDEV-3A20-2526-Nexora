# NEXORA — Integrated Project (PI) | Esprit School of Engineering

> Full-stack tourism & e-commerce platform combining a **Symfony web app** and a **JavaFX desktop app**, sharing the same MySQL database for real-time synchronization.

---

- **School:** Esprit School of Engineering

- **Project Type:** Integrated Project (PI)
- **Live Web App:** [nexora.alwaysdata.net](https://nexora.alwaysdata.net)

---

## 🗂️ Project Structure

```
nexora_finale/
├── nexora_symfony/     # Web application (PHP / Symfony 7)
└── nexora_java/        # Desktop application (Java / JavaFX)
```

Both applications connect to the **same MySQL database** (`java` @ `localhost:3306`), enabling real-time data synchronization between web and desktop.

## 🚀 Features

### 🛍️ E-commerce
- Partners add products with variants (size, color, etc.) from web or desktop
- Products sync in real time across both platforms
- Client cart (`panier` table) shared between web and desktop
- Order management, promotional codes, payment integration

### 🎯 Activities & Excursions
- Browse and filter activities by type, location, date
- Participation request system with partner acceptance workflow
- Auto-refresh payment button when request is accepted (every 8 seconds)
- Integrated payment (Konnect + bank card + cash)

### 🌍 Destinations
- Explore travel destinations with images and descriptions
- Community discussions and reviews per destination

### ⭐ Reviews & Comments
- Clients leave reviews with star ratings (1–5)
- Real-time sentiment analysis via Gemini AI
- Partner response suggestions generated by AI
- Comment system with full CRUD per review

### 📋 Complaints (Réclamations)
- Clients submit complaints linked to activities
- Full lifecycle management for partners and admins

### 🔔 Notifications
- Real-time cross-platform notifications
- Badge counter on desktop and web
- Partner notified on new participation requests

### 🤖 AI Chatbot
- Voice search with Gemini keyword extraction
- Product recommendations by budget
- Smart assistant for navigation

### 🔐 Authentication
- Standard email/password with bcrypt
- Face recognition login
- Fingerprint login
- Google OAuth 2.0
- Two-factor authentication (2FA)
- Brute-force protection (progressive lockout)

### 📊 Admin Dashboard
- User management (block, unblock, roles)
- Content moderation (toxic content detection)
- Sales analytics and partner statistics
- Promo code management

### 💳 Payments
- Konnect (Flouci) integration
- Bank card simulation
- Cash on delivery
- Payment history per client

## 🛠️ Installation

### Prerequisites
- PHP 8.2+, Composer
- Java 17+, Maven
- MySQL 8.4
- Node.js (for Symfony asset mapper)

### Symfony Web App

```bash
cd nexora_symfony
composer install
# Configure .env — set DATABASE_URL to your MySQL instance
php bin/console doctrine:migrations:migrate
symfony server:start
```

### Java Desktop App

```bash
cd nexora_java
# Configure src/main/java/com/pi/utils/mydatabase.java
# Set URL, USERNAME, PASSWORD to match your MySQL instance
mvn javafx:run
```

### Database

Both apps must point to the **same MySQL database**.

```
# Symfony (.env)
DATABASE_URL="mysql://root:@127.0.0.1:3306/java?serverVersion=8.4.7&charset=utf8mb4"

# Java (mydatabase.java)
URL = "jdbc:mysql://localhost:3306/java"
USERNAME = "root"
PASSWORD = ""
```
