## 📖 Glossaire

### Termes Techniques

**Test Unitaire** : Test qui vérifie une unité de code isolée (méthode, classe) sans dépendances externes.

**Mock** : Objet simulé utilisé dans les tests pour remplacer une dépendance réelle.

**Assertion** : Vérification d'une condition dans un test (ex: `assertTrue()`).

**AAA Pattern** : Arrange-Act-Assert, structure recommandée pour les tests.

**Service Métier** : Classe contenant la logique métier de l'application.

**Règle Métier** : Contrainte ou validation définie par les besoins fonctionnels.

**PHPUnit** : Framework de tests unitaires pour PHP.

**TestCase** : Classe de base pour les tests unitaires dans PHPUnit.

**setUp()** : Méthode exécutée avant chaque test pour initialiser l'environnement.

**expectException()** : Méthode PHPUnit pour vérifier qu'une exception est levée.
